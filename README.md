# AI projects

Demo builds of AI chatbots, voice agents and automations for small businesses, by [Joginder Kaur](https://github.com/Joginder-Kaur).

I built these to learn this work properly and to show clients what I can set up for them. Each clip is a short cut of a longer screen recording. The businesses in the demos are examples, not client projects.

| Project | Built with |
|---|---|
| [Custom AI chat interface](#custom-ai-chat-interface) | React |
| [Customer support chatbot](#customer-support-chatbot) | Botpress, React |
| [AI voice receptionist](#ai-voice-receptionist) | Vapi |
| [Appointment booking assistant](#appointment-booking-assistant) | n8n, Telegram, Google Calendar |
| [Answers from your documents (RAG)](#answers-from-your-documents-rag) | n8n, OpenAI, Pinecone |
| [Lead list builder](#lead-list-builder) | n8n, Google Sheets |

## Custom AI chat interface

https://github.com/user-attachments/assets/97aa0131-c0ea-4b43-a0b5-af2ffc9629c2

A chat window built in React, with message history, a typing indicator, suggested prompts and file attachments. It can sit on any website and connect to the AI model or chatbot platform the business uses.

## Customer support chatbot

https://github.com/user-attachments/assets/996c1daa-f8fe-4761-a27b-abbd681be25e

A support chatbot for an online wine shop, built in Botpress and added to a React website. It answers questions about products from the shop's own catalog.

## AI voice receptionist

https://github.com/user-attachments/assets/9f2d91cb-40fc-466c-a75c-fe616bfec4e1

A phone agent built in Vapi that takes a booking by voice. It asks for the caller's preferred date and time, checks what is free, offers other slots if needed, and collects the caller's details.

## Appointment booking assistant

https://github.com/user-attachments/assets/a0d61c78-9eda-423e-aab1-3ade4d5f80b0

A chat assistant in Telegram, built in n8n. It checks free slots in Google Calendar, collects the person's name, contact details and reason for the visit, and books the appointment.

## Answers from your documents (RAG)

https://github.com/user-attachments/assets/a44145ef-19a0-4875-a459-b5b60503e54f

A chat assistant for a photography studio that answers questions about packages, prices and turnaround times from the studio's own documents. Built in n8n with OpenAI embeddings and a Pinecone vector store.

## Lead list builder

https://github.com/user-attachments/assets/f9f8e429-e902-4171-b70b-a5c50c3ef799

An n8n workflow that takes a business type and location from a Google Sheet, collects matching businesses from Google Maps, finds and checks their email addresses, and adds the results back to the sheet.

## AI sales assistant

https://github.com/user-attachments/assets/9a637425-a585-4405-9c78-b5f93c1b7d74

A chat assistant that recommends products from a catalog stored in Airtable and shares customer testimonials with links when asked. Built in n8n with OpenAI.

## Form-to-email automation

https://github.com/user-attachments/assets/d30fc390-3433-4588-8fad-00daf3e27c1e

An n8n workflow for sponsorship enquiries. When someone submits the form, it checks the budget, sends an approval or decline email through Gmail, and logs the enquiry in Google Sheets.
